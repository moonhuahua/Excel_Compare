# Excel_Compare 2026.10.22

首次公开发布当前稳定版本，应用逻辑与本地已验证的正式程序一致。

- `Excel_Compare.exe`：独立主程序。
- `Excel_Compare-Windows.zip`：主程序、使用说明，以及配套 AHK / 示例文件。
- `SHA256SUMS.txt`：发布资产 SHA-256 校验值。

运行环境：Windows，.NET Framework 4.5.2 或兼容的 4.x 运行时；AHK 脚本需要 AutoHotkey v1.1.33+。

源码在仓库中提供；依赖缓存、编译临时文件和本机验证记录未上传。
